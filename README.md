# Personal Companion · оновлення для персональної бети

[Інсталятори й інструкції](https://github.com/hirchak/Personal-Companion-Updates/releases).
Для macOS 14 або новішої на Apple Silicon. Завантажуйте DMG потрібної версії та звіряйте SHA-256.

Після першого встановлення актуальної базової збірки програма сама перевіряє оновлення під час
роботи. Кнопка «Оновити» зберігає роботу локально, перевіряє резервну копію та підписаний пакет,
встановлює сумісну нову версію й перезапускає програму. Build652 потребує одного ручного переходу;
покрокова інструкція є серед файлів релізу (`User-Guide-uk.md`). Не запускайте постійно з DMG.

Це personal beta: пакети оновлення ZIP та appcast мають підпис видавця Ed25519. Developer ID і
Apple notarization поки відсутні; початкове відкриття може потребувати особистого дозволу macOS.
DMG для першого встановлення перевіряється за контрольною сумою, отриманою від довіреного власника.
Не вимикайте захист Mac. Програма не є медичним сервісом.

Цей репозиторій містить лише публічні файли постачання й метадані. Канал оновлень не отримує ваші
записи, аудіо, авторизацію чи резервні копії; вони залишаються на вашому Mac. Вихідний репозиторій
та його історія тут не публікуються. Інсталятор містить необхідний програмний код і локальний runtime.

Не додавайте особисті записи, токени, аудіо або повні системні звіти в Issues. Повідомляйте про
проблему приватно власнику пакета: версія/build, назва дії та короткий опис без приватного змісту.
